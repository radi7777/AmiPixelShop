Part I - Getting started

1. About AmiPixelShop

AmiPixelShop is a modern, layer-based image editor written natively for the Amiga. It is not a port and nothing was reverse-engineered: every function was rebuilt from scratch in C and 68k assembler, modelled on the workflow of today's professional image editors.

Highlights:

  • Layers, groups, layer masks, clipping masks, adjustment layers and layer styles
  • Selection tools including Quick Selection and Color Range, Pen tool with paths
  • Editable type with TrueType fonts
  • Retouching: Clone Stamp, Spot Healing, Dodge/Burn, Liquify
  • AI features: Generative Fill, Remove, Extend, Select Subject, Remove Background
  • Amiga colors: optimal palettes for OCS/ECS/AGA, EHB and HAM, IFF ILBM import and export
  • Opens PSD files with layers

This is an early beta. Expect bugs - and please report them (see Reporting bugs).

2. Requirements

CPUPiStorm (Emu68, JIT-emulated 68040 with FPU) - recommended and tested.
A real 68060 with FPU might work, but will be slow at high resolutions (untested).
GraphicsRTG (Picasso96 / P96) with a 24 or 32 bit screen mode, 1024×600 up to 1920×1080. Without Picasso96 it uses cybergraphics.library (CyberGraphX, MorphOS) - untested there, feedback welcome.
OSAmigaOS 3.2 (tested with 3.2.3).
MemoryAt least 128 MB Fast RAM, more for large images. A layer of 1920×1080 needs about 8 MB.
For the AI featuresA TCP/IP stack (Roadshow), AmiSSL v5, an internet connection and an OpenRouter API key. Everything else works without them.
Tested onAmiga 500 + PiStorm (Raspberry Pi, Emu68), AmigaOS 3.2.3, P96, Roadshow, AmiSSL 5.27.

3. Installation and first start

  1. Unpack the archive anywhere, e.g. Work:. You get a drawer AmiPixelShop.
  2. Start AmiPixelShop from Workbench (also with Shift-click on picture icons) or from the Shell, optionally with pictures: AmiPixelShop Work:Pictures/photo.jpg
  3. On the first start a screen mode requester appears. Choose an RTG mode with 24 or 32 bit. AmiPixelShop opens its own screen for maximum speed. Change it later with Edit > Screen Mode...
  4. For the Type tool you need TrueType fonts (.ttf / .otf) in FONTS:truetype/, FONTS:_ttf/ or in a Fonts drawer next to the program.
  5. For the AI features: install AmiSSL v5 (Aminet: util/libs/AmiSSL-v5-OS3) and enter your key with Edit > AI API Key... - see chapter 14.

Updates. When the Amiga is online (Roadshow and AmiSSL v5), AmiPixelShop checks GitHub for a newer version at start. If there is one, it asks: Install downloads it, replaces the program, this Guide and its pictures, and restarts AmiPixelShop (your icon stays as it is; the previous program is kept as AmiPixelShop.old). Later asks again next time, Skip This Version stays quiet until an even newer one comes out. Check by hand with Help > Check for Updates...; turn the check at start off with Help > Check for Updates at Start. Without a network nothing happens.

4. The workspace

Menu barAll commands. Entries that cannot be used right now are greyed out. Menus open with a click.
Options barSettings of the current tool, below the menu.
ToolbarAll tools (left). A small triangle means more tools in the same slot: hold the mouse button or right-click to choose. Edit > Toolbar... chooses which tools are shown. Below the tools: foreground and background color - click to open the Color Picker, X swaps, D resets.

Status barZoom (click to type a value), document size, redraw time and messages.
RulersView > Rulers (Ctrl+R) shows pixel rulers above and left of the image.

Navigation: hold Space and drag to scroll; mouse wheel or Ctrl++ / Ctrl+- to zoom; Ctrl+0 fits the image, Ctrl+1 shows 100%.

Guides: drag from the top ruler for a horizontal guide, from the left ruler for a vertical one. View > New Guide... places one at an exact position. To move a guide, drag it with the Move tool (or hold Ctrl with most other tools); drag it out of the image area (e.g. back onto the ruler) to delete it. Rectangle and Ellipse Marquee, Shapes and Crop snap to guides and to the image edges (View > Snap). The Move tool snaps the edges and the center of the moved layer (or selection) to guides, the image edges and the image center. A guide you drag snaps to the image edges and center and to the edges and center of every visible layer. View > Show Guides (Ctrl+;) hides them, Lock Guides stops them from moving, Clear Guides removes all. Guides are saved in .aps files and follow Image Size, Canvas Size, Crop and 90°/180° rotations; they are not part of Undo.

5. Documents: new, open, save

File > New... (Ctrl+N) opens the New Document dialog. Pick a preset from the tabs Recent, Photo, Print, Web, Mobile, Film & Video, Amiga or Saved, or type your own size on the right. Save Preset... keeps your own sizes in the Saved tab.

The Amiga tab has the classic screen formats: PAL and NTSC Lowres, Hires, Interlace and Overscan, Super-Hires, Productivity, AGA, EHB, HAM6 and HAM8, a Workbench icon and an RTG size. The Color Mode of such a document is remembered for Reduce Colors and the IFF export. You always paint in full color - the colors are reduced at the end.

  • Open (Ctrl+O): AmiPixelShop, PSD, PNG, JPEG, IFF and everything your datatypes can read - see File formats.
  • Save (Ctrl+S) keeps everything (layers, masks, text, paths, AI prompts) in the native .aps format. Save As with the ending .png, .jpg or .iff writes a flattened picture.
  • File > New from Clipboard and Copy/Paste work with the Amiga clipboard.
  • File > Revert (F12) goes back to the saved version.

7. Selections

  • Tools: Marquee, Lasso, Quick Selection and Magic Wand (see Tools).
  • Select > Subject - the AI finds the main subject (see chapter 19).
  • Select > Color Range... - selects by color with fuzziness, with live preview.
  • Select > Grow / Similar - extends the selection to similar colors (Magic Wand tolerance).
  • Select > Modify - Feather (Shift+F6), Expand, Contract, Border (a soft band of the given width along the edge), Smooth (removes jagged edges and stray pixels).
  • Select > Inverse (Shift+Ctrl+I), Deselect (Ctrl+D), Reselect (Shift+Ctrl+D).

What you can do with a selection:

  • Edit > Fill... and Edit > Stroke... (inside, center or outside).
  • Ctrl+J copies it to a new layer, Shift+Ctrl+J cuts it.
  • Filters and adjustments only work inside it.
  • Generative Fill and Remove from the task bar.

8. Layers, groups and masks

Layers panel

  • Click the eye to show/hide, click a row to make it active, double-click the name to rename.
  • Drag rows to change the order or to drop a layer into a group.
  • Each layer has a blend mode (25 modes: Multiply, Screen, Overlay, Soft Light, Color, ...), Opacity and Fill. Lock: transparency, pixels, position or all.
  • Several layers: Ctrl+click adds, Shift+click selects a range, Select > All Layers (Alt+Ctrl+A). Selected layers can be moved, grouped, merged or deleted together.

Groups

Ctrl+G groups the selected layers. Fold with the triangle. Blend mode Pass Through or isolated, with opacity and mask.

Layer masks

  • Add with the mask button at the bottom of the panel or Layer > Layer Mask.
  • Click the mask thumbnail to paint into the mask: black hides, white shows.
  • Shift+click the mask thumbnail disables/enables it (or Disable in the Properties panel).
  • The small chain between the thumbnails links layer and mask - click it to unlink.

More layer types

  • Clipping masks (Alt+Ctrl+G): a layer is only visible where the layer below has pixels.
  • Adjustment layers (round button, or Layer > New Adjustment Layer): non-destructive Brightness/Contrast, Levels, Curves, Hue/Saturation, Desaturate, Invert, Threshold, Posterize.
  • Layer styles (fx button): Drop Shadow, Outer Glow, Stroke.
  • Generative layers: results of the AI features, see chapter 20.

10. Type

  • Choose the Type tool and click into the image to type - or drag a box for paragraph text that wraps automatically.
  • Return starts a new line, Ctrl+Return or the Commit button finishes, Esc cancels.
  • Click an existing text with the Type tool to edit it again.
  • Options bar and Type menu: font, size, alignment, anti-aliasing (Smooth, Sharp, None), Character... (tracking and leading), Paste Lorem Ipsum.
  • Layer > Rasterize Type turns text into pixels.

11. Pen tool and paths

  • Click sets a corner point, drag sets a curve point with handles.
  • Click the first point to close the path. Return ends an open path, Backspace removes the last point.
  • Drag points or handles to edit the path.
  • Options bar and Paths panel: Make Selection (Ctrl+Return), Fill Path (foreground color), Stroke Path (with the current brush), Delete Path.
  • Path changes can be undone; the path is saved in .aps files.

12. Transform and Liquify

  • Edit > Free Transform (Ctrl+T): scale, rotate, flip - Return applies, Esc cancels. The options bar switches between Free, Distort (move each corner freely), Perspective (the opposite corner follows) and Warp (bend the image with a 4×4 mesh).
  • Filter > Liquify... (Shift+Ctrl+X) works directly on the canvas: Forward Warp pushes pixels, Reconstruct paints the original back, Pucker, Bloat and Twirl keep working while you hold the mouse. Size and Pressure are in the options bar; Return applies, Esc cancels.
  • Image: Image Size, Canvas Size, Image Rotation (180°, 90°, arbitrary, flip canvas), Crop, Trim, Reveal All, Duplicate. Type layers stay editable when the canvas is rotated or flipped, and also with Free Transform, Flip and Rotate (Distort, Perspective and Warp convert them to pixels, as in Photoshop).
  • Pixels moved outside the canvas are kept and come back with Image > Reveal All or when moved back.

13. Adjustments and filters

Image > Adjustments: Brightness/Contrast, Levels (Ctrl+L), Curves (Ctrl+M), Hue/Saturation (Ctrl+U), Desaturate, Invert (Ctrl+I), Threshold, Posterize - all with live preview. For non-destructive work use adjustment layers.

Filter: Box Blur, Gaussian Blur, Motion Blur, Add Noise, Median, Mosaic, Sharpen, Sharpen More, Unsharp Mask, Emboss, Find Edges, High Pass, Liquify. Ctrl+F repeats the last filter.

With a selection, filters only work inside it. With a mask active, they work on the mask.

Filter > Amiga: Reduce Colors and palettes, see chapter 22.

Levels shows the histogram of the layer (or of the selection). Drag the triangles under it: black point, gamma (gray) and white point; the lower bar sets the output range. The darkened bars are the tones that get clipped. Click a number to type a value. With Channel you adjust Red, Green or Blue on their own (for example to remove a color cast); the RGB values are applied on top.

Auto sets black and white point so that only 0.1 % of the pixels are clipped - a quick, safe contrast boost. Reset goes back to 0 / 1.00 / 255.

Curves shows the histogram of the chosen channel behind the curve.

As adjustment layer: the sliders are in the Properties panel, the button Edit Levels... opens this dialog with the histogram of the image below.
Part III - AI features

14. Overview and setup

AmiPixelShop can use current image AI models to fill, remove, extend and cut out image content - directly from the Amiga, over an encrypted connection.

FunctionWhereResult
Generative FillTask bar, Edit menuNew content in the selection, from your description
RemoveTask bar, Edit menu, Spot Healing BrushObjects disappear, the background is continued
ExtendTask bar on empty canvasThe image is continued into transparent areas
Select SubjectTask bar, Select menuSelection of the main subject
Remove BackgroundTask bar, Layer menuLayer mask that hides the background

The work is done by models on the internet. AmiPixelShop sends only the part of the image that is needed, and puts the result back only inside your selection on a new layer - the rest of the picture stays pixel-identical and the original layer is never changed.

What you need

  1. Roadshow (bsdsocket.library) and AmiSSL v5 (Aminet: util/libs/AmiSSL-v5-OS3).
  2. An account at openrouter.ai with some credit. OpenRouter gives access to many image models with one key. Create a key under Keys; it is a good idea to set a credit limit for it (for example 5 $).
  3. Enter the key in AmiPixelShop: Edit > AI API Key..., paste or type it, press Return. AmiPixelShop stores it in ENVARC:AmiPixelShop/openrouter.key, checks it at once and shows how much has been used and how much of the limit is left.

Alternative: Google Gemini directly. Instead of OpenRouter you can use a Gemini API key from aistudio.google.com/apikey (billing is set up in Google AI Studio; a Gemini app subscription such as Google AI Pro does not include API access). Choose Provider: Google Gemini in Edit > AI Settings..., then enter the key with Edit > AI API Key... - it is stored in ENVARC:AmiPixelShop/gemini.key. The same Nano Banana models are used; the status bar shows no costs in this mode (see the usage page in Google AI Studio).

Alternative: ComfyUI on a PC in your network. Free and private - nothing leaves your LAN. No AmiSSL needed (plain HTTP).

  1. On the PC, start ComfyUI with --listen (for example python main.py --listen) so the Amiga can connect, allow port 8188 in its firewall, and install the models of the workflow.
  2. In AmiPixelShop choose Provider: ComfyUI (LAN) in Edit > AI Settings... and enter the address of the PC, for example 192.168.1.20:8188, with Edit > AI API Key... (stored in ENVARC:AmiPixelShop/comfyui.server). AmiPixelShop connects and shows the GPU of the PC.
  3. The work is done by a ComfyUI workflow in API format. AmiPixelShop sends the image with the area to fill made transparent - the Load Image node turns that into the MASK - and takes the image of the Save Image node.
Workflow fileUsed for

AmiPixelShop looks for them in ENV:AmiPixelShop/, ENVARC:AmiPixelShop/ and the ComfyUI drawer next to the program. For your own workflow: Workflow > Export (API) in ComfyUI, then in a text editor put "%image%" as the image of the Load Image node, %prompt% into the prompt text - or %task% for editing models such as FLUX 3: a complete instruction that names the region (%box% gives just the region as [y_min, x_min, y_max, x_max], 0 to 1) - and optionally "%seed%" as the seed (a new one for every request, so Generate again gives new variants). The first request can take a while because the PC loads the models. If a model is missing, the error message lists the ones ComfyUI has. See ComfyUI/ReadMe.txt.

For troubleshooting, every AI request writes its steps to T:AmiPixelShop-AI.log (sizes, HTTP status, where it stopped).

Costs and privacy

  • One request costs about 3.4 to 4 US cents with the default models (Nano Banana Pro: about 13 cents). The status bar shows the cost of every request and the total of the session.
  • A request takes about 10 to 15 seconds. You can keep working meanwhile.
  • The selected part of the image is sent to OpenRouter (if used) and the model provider (Google); with ComfyUI it only goes to your PC. Do not use the AI features for pictures that must stay private.

16. Generative Fill

  1. Select an area with any selection tool. A rough rectangle is fine.
  2. Click Generative Fill in the task bar (or Edit > Generative Fill...).
  3. Describe what should appear, in English works best, for example a small brown dog sitting in the grass.
  4. Press Return or click Generate.

After about 10-15 seconds the result appears on a new layer named Gen: ... with your selection as layer mask - the original is untouched. Light, perspective and colors are matched to the picture.

Leave the description empty to fill the area so that it fits the surroundings.

19. Select Subject and Remove Background


Select > Subject
Layer > Remove Background
  • Select Subject creates a selection of the main subject - with fine edges, also in hair and fur. Use it for Ctrl+J, filters, adjustments or as a starting point for further selection work.
  • Remove Background adds a layer mask to the active layer that hides the background. Nothing is deleted: Disable the mask to see everything again, paint into the mask to correct it, or Apply it to remove the background for good.
  • Both are in the task bar when nothing is selected. Remove Background needs a pixel layer without a mask.

20. Generative layers and variants

Every Generative Fill, Remove or Extend creates a generative layer (Gen: ...). When it is active, the Properties panel shows:

  • the description you used,
  • < 1 / 2 > - flip through the variants,
  • Generate again - asks the AI for one more variant of the same area with the same description.

Up to six variants are kept while the document is open. The shown variant is what you see and what is saved. Description and type of the layer are saved in .aps files, so Generate again also works later.

Generative layers are normal pixel layers with a mask: move them, change opacity, paint into the mask to blend the edge, or merge them down when you are done.

21. AI settings, costs and tips

Edit > AI Settings...

Fill modelUsed for Generative Fill with a description. Nano Banana 2.1 (default, about 4 cents), Nano Banana Pro (best quality, about 13 cents, slower), Flash Lite (fastest, simpler results).
Remove/ExtendUsed for Remove, Extend, Select Subject and Remove Background. Flash Lite (default, fast, about 3.4 cents) or Nano Banana 2.1.
Variants1, 2 or 3 variants per Generative Fill. Each variant is a separate request and costs extra.

Tips

  • Select generously: include shadows and reflections of an object you want to remove.
  • Small areas: AmiPixelShop automatically sends enough surroundings so the AI understands the scene.
  • Not happy? Click Generate again, or paint into the mask of the generative layer to keep only the good parts.
  • Write descriptions in English and describe the thing, not the action: a red rowing boat instead of add a boat.
  • Large changes: several smaller steps often look better than one huge selection.

Part IV - Amiga

22. Amiga colors and IFF

Reduce Colors

Filter > Amiga > Reduce Colors... builds the best palette for the image and shows the result live, together with the palette:

PaletteAdaptive (24 bit colors, for AGA and RTG), OCS 12-bit (4 bit per channel, like OCS/ECS hardware), MagicWB (the 8 MagicWB colors stay, the rest is chosen for the image), Grayscale or Fixed (a given palette, see below).
ModeNormal with 2 to 256 colors, EHB (32 colors plus 32 half-bright ones - both halves are optimized together), HAM6 and HAM8 (each pixel picks the best of a palette color or changing one channel of its left neighbour).
DitherNone, Floyd-Steinberg (smoothest gradients), Atkinson (crisper, keeps more contrast) or Ordered (regular 8×8 pattern, good for animations). Amount sets the strength.
Optimize PaletteRefines the palette further for the best match as the eye sees it.

IFF export

File > Export as IFF ILBM... writes a standard IFF picture (also Save As with the ending .iff): with the palette of the last Reduce Colors, or reduced automatically to the color mode of the document. The screen mode (Lowres/Hires, Interlace, EHB, HAM) is stored in the file, so viewers and paint programs show it correctly. The palette and settings are also saved in .aps files.

Fixed palettes

For graphics that must fit an existing picture or game:

  • Filter > Amiga > Load Palette... takes the palette of any IFF picture or palette file and opens Reduce Colors with Palette: Fixed, so you see at once how the image looks with these colors.
  • Use Current Palette as Fixed keeps the palette of the last reduction for further images.
  • Save Palette... writes it as an IFF palette file (as DPaint does).
  • The fixed palette is saved in .aps files.

Brushes and foreign IFF files

  • Transparent areas are kept. With transparency, color 0 is reserved for transparent pixels (the usual DPaint brush); the export stores it as transparent color. For HAM, or when a palette has no free entry, a mask plane is written instead.
  • IFF brushes with a transparent color or a mask plane open with their transparency.
  • IFF pictures from other programs open with their palette and mode: 1 to 8 bitplanes, EHB, HAM6, HAM8, 24 bit, mask plane and DPaint PBM. Opened, edited and exported again, the palette stays the same.

26. Known limitations

  • 8 bit per channel RGB only; no CMYK, no 16 bit.
  • Up to 64 layers per document.
  • PSD files can be opened but not saved.
  • Very large images need a lot of memory (each layer is stored as 32 bit tiles; empty and plain white mask areas take no memory).
  • AI results are generated at about 1 megapixel and scaled to the selection - very large selections look softer.
  • Variants of generative layers are not saved, only the one shown.
  • No graphics tablet support.
